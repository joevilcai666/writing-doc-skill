# Writing Doc v0.2.0

Writing Doc now helps readers understand research, concepts, product designs, and decisions as well as technical instructions. It groups sources by question, checks that figures use comparable measures, and makes clear what the evidence can support.

- Write for the reader’s decision, understanding, or next action. For a complex mechanism, show how the result changes when an important condition changes.
- Keep supplied commands intact. Explain what the source specifies about an API and identify gaps that matter to the implementer.
- For review-only requests, return findings and fixes.
- Run the same repository JSON depth check across supported Python decoders.

A blinded comparison found a technical-document gain and similar knowledge-task scores. The knowledge result fell below the proposed eight-point target.

The package contains one shared skill for Codex, Claude Code, and compatible Agent Skills clients. The Release includes a ZIP and its SHA-256 checksum. See the [verification record](../verification/v0.2.0.md) for actual model output comparisons and verification limits.
