# Writing Doc v0.2.0 verification

Date: 2026-11-26. Platform: macOS arm64.

## Source and review

The release starts from the NotebookLM-inspired v2 candidate supplied in ChatGPT. Both members of the recovered revision 2 ZIP match the previously saved source files byte for byte. The ZIP SHA-256 and case hashes are in [provenance](../../evals/experiments/v0.2.0-followup/provenance.json).

Review tightened the evidence and review-only instructions, protected supplied command spelling, and clarified which API details to leave unspecified. A first follow-up run exposed an overstatement about group differences and repeated figures. The final skill asks the writer to distinguish observed differences from possible bias and to use each figure where the reader needs it.

## Regression, Release Gate, and package

The original suite had 126 tests. Its deep-JSON case exposed different decoder limits across Python versions. The release sets an explicit 64-level limit and adds a test for 64 and 65 levels and brackets inside strings.

- `python3 -m unittest discover -s tests -v`
- `python3 scripts/check_repo.py --release`
- `python3 scripts/build_release.py --output <directory>` in two empty output directories, followed by ZIP integrity, byte comparison, and SHA-256 checks.

The Release Gate covers structure, required files, links, the Lantern rubric, the unit suite, current/index/history privacy, Git whitespace, the Agent Skills validator, Codex compatibility, and Claude strict validation. Codex CLI has no `plugin validate` command. The gate uses real isolated marketplace registration, install, listing, and a comparison of all skill bytes. The Agent Skills validator uses PyYAML 6.0.3. The repository has zero registered local runners. The checks run directly on the local release commit. [Gate output](v0.2.0-gate.txt).

The Lantern example is fictional. The local rubric checks document structure and literals. It neither runs the service nor scores the model outputs above.

See the copy of this record on `main` for the exact release commit, public download, and install checks.
